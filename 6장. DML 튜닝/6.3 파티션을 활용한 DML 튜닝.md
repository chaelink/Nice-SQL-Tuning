### 6.3 파티션을 활용한 DML 튜닝

- 파티셔닝 : 테이블 또는 인덱스 데이터를 특정 컬럼(파티션 키) 값에 따라 별도 세그먼트에 나눠서 저장하는 것

<br>

테이블 파티션 종류
1. Range 파티션
    - 오라클 8 버전부터 제공된 가장 기초적인 방식, 주로 날짜 컬럼을 기준으로 파티셔닝
    - 파티션 pruning : 조건절을 분석하여, 읽지 않아도 되는 파티션 세그먼트를 액세스 대상에서 제외하는 기능
    - 파티션 테이블도 인덱스 액세스는 가능, 하지만 파티션 pruning이 더 빠름
2. 해시 파티션
    - 오라클 8i 버전부터 제공
    - 파티션 키 값을 해시 함수에 입력, 반환받은 값이 같은 데이터를 같은 세그먼트에 저장
    - 파티션 개수만 사용자가 결정, 알고리즘은 오라클 내부 해시함수
3. 리스트 파티션
     - 오라클 9i 버전부터 제공
     - 사용자가 정한 그룹핑 기준에 따라 데이터 분할 저장
  
<br>

- 테이블 파티션 구분
  - 비파티션 테이블
  - 파티션 테이블

<br>

- 인덱스 파티션 : 대용량 테이블의 조회 성능 향상을 위해, 인덱스를 논리적/물리적으로 분할
  - 파티션 인덱스
    - 로컬 파티션 인덱스 : 테이블의 파티션 구조와 동일하게 인덱스도 파티션되는 방식
    - 글로벌 파티션 인덱스 : 테이블의 파티션 구조와 독립적으로 인덱스도 파티션되는 방식
  - 비파티션 인덱스  
  - Prefixed vs Non-prefixed (구성 방식에 따른 분류)
      - Prefixed: 인덱스 구성 컬럼 중 **선두 컬럼이 파티션 키**인 방식
      - Non-prefixed: 인덱스 구성 컬럼 중 **선두 컬럼이 파티션 키가 아닌** 방식
